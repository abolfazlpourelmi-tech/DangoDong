# دنگودونگ — اپلیکیشن تقسیم هزینه گروهی

نسخه موبایل فارسی برای Android و iOS با React Native و Expo، با هویت بصری Playful Fintech و فونت Estedad.

## اجرا

```bash
npm install
cp .env.example .env
npm start
```

در فایل `.env` فقط `Project URL` و `Publishable key` پروژه Supabase را قرار دهید. رمز دیتابیس و کلید `service_role` هرگز نباید داخل اپ یا فایل `.env` کلاینت قرار بگیرند. فایل‌های محیطی در Git نادیده گرفته می‌شوند.

پس از نمایش QR Code، آن را با Expo Go اسکن کنید. برای شبیه‌ساز نیز می‌توانید از `npm run ios` یا `npm run android` استفاده کنید.

## بررسی کیفیت

```bash
npm test
npm run typecheck
```

## امکانات نسخه فعلی

- شروع بدون شماره، و افزودن اختیاری شماره موبایل از «حساب من» برای بازیابی اطلاعات روی دستگاه دیگر
- شروع از وضعیت خالی و ساخت ماجرای جدید برای رستوران، سفر، آشپزی یا هر هزینه مشترک
- مدیریت چند ماجرا با صفحه جداگانه برای موارد در جریان و تمام‌شده
- پایان‌بندی ماجرا با خلاصه هزینه و انتقال‌های باقی‌مانده
- مرکز اعلان یکپارچه برای نمایش بدهی و طلب هر شخص در هر ماجرا
- ثبت واقعی پرداخت تسویه و به‌روزرسانی خودکار مانده‌ها و اعلان‌ها
- نمایش شماره کارت دریافت‌کننده در صفحه تسویه و درخواست شماره کارت از کاربری که هنوز ثبتش نکرده
- ویرایش و حذف هر خرج فقط توسط همان کسی که ثبتش کرده
- جزئیات هزینه و فیلتر هزینه‌ها بر اساس «همه»، «این هفته» و «پرداخت‌های من»
- تأیید دومرحله‌ای پیش از ثبت پرداخت تسویه
- افزودن اعضای ماجرا
- پشتیبانی از نماینده مالی با تعداد سهم خانوادگی (مثلاً خانواده‌های ۴، ۳ و ۲ نفره)
- ثبت سریع هزینه با جریان مبلغ‌محور
- پشتیبانی از ارقام فارسی، عربی و انگلیسی
- دسته‌بندی تصویری هزینه‌ها
- انتخاب افراد شریک در هر هزینه
- پیش‌نمایش زنده سهم هر نفر
- تقسیم مساوی، مبلغ دلخواه و ثبت ریز اقلام هر نفر
- تقسیم دقیق مبلغ و مدیریت باقی‌مانده گرد کردن
- محاسبه قطعی کمترین تعداد انتقال برای گروه‌های تا ۱۲ مانده فعال
- ترجیح پرداخت مستقیم بدهکار به طلبکار در جواب‌های هم‌ارزش
- صفحه‌های خانه، خرج‌ها و تسویه با رابط RTL
- فونت فارسی Estedad در شش وزن
- تصویرسازی و آیکن اختصاصی clay/3D
- هپتیک موفقیت و بازخورد دسترس‌پذیر

اطلاعات ماجراها، اعضا، هزینه‌ها و تسویه‌ها روی Supabase ذخیره می‌شوند و بین دستگاه‌های اعضای یک ماجرا به‌صورت زنده همگام می‌مانند.
